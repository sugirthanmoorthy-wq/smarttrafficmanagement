Java Spring Boot REST API Connection

The frontend connects to a Java Spring Boot REST API or built-in Java HTTP Bridge. If no server is running, the in-browser simulation engine runs the exact same algorithms offline with zero data loss.

Default: http://localhost:8080
Available Endpoints:
  • GET /api/network/junctions
  • GET /api/network/roads
  • POST /api/routes/find
  • POST /api/traffic/generate
  • POST /api/emergency/request
  • GET /api/signals
