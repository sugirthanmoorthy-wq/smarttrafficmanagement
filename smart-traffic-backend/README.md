# Smart Traffic Management System

## Project Overview
An intelligent traffic management system
that prioritizes emergency vehicles and
determines optimal routes using Dijkstra's
algorithm.

## Technologies
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript

## Data Structures
- Graph
- Priority Queue
- Queue
- HashMap

## Main Features
- Automatic vehicle generation
- Emergency vehicle prioritization
- Shortest path calculation
- Traffic signal management
- Traffic monitoring

## Execution
1. Configure MySQL.
2. Configure application.properties.
3. Run TrafficApplication.java.
4. Open the frontend.
